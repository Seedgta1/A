## Setup richiesto per `greenetadmin`

Ho provato a scaricare il repository `https://github.com/antoniolaudieri/greenetadmin.git`, ma al momento l'URL restituisce **404 Not Found** in questo ambiente.

Comandi eseguiti:

```bash
git clone https://github.com/antoniolaudieri/greenetadmin.git
curl -I https://github.com/antoniolaudieri/greenetadmin
```

Per procedere con la configurazione e le modifiche servono una di queste opzioni:

1. repository pubblico e raggiungibile;
2. URL corretto del repository;
3. accesso autenticato (token) se il repo è privato.
